## 0. 一句话结论

北邮本科教务系统是 **强智科技（QZDATASOFT）** 的教务系统（`jsxsd` 部署），**不是正方（jwglxt）**。它有**两套入口**：

| 入口 | 地址 | 形态 | 适用 |
|---|---|---|---|
| PC 版（传统） | `https://jwgl.bupt.edu.cn/jsxsd/` | **服务端渲染 HTML**（`table#kbtable`） | 校园网内，或经 WebVPN |
| 移动/微服务版 | `https://jwglweixin.bupt.edu.cn/bjyddx` | **纯 JSON API** | 有 token 即可用，**对 App 最友好** |

课表页面（PC）：`/jsxsd/xskb/xskb_list.do`
课表 API（移动）：`POST /bjyddx/student/curriculum`

> ⚠️ 关键限制：`jwgl.bupt.edu.cn` **在公网 DNS 上不存在**（NXDOMAIN），只在校园网内网解析。
> 实测（阿里 DoH `223.5.5.5`）：
> `{"Status":3,...,"Question":{"name":"jwgl.bupt.edu.cn.","type":1},"Authority":[{"name":"bupt.edu.cn.",...}]}`
> ——即该校内域名走内网分离解析。校外必须经 WebVPN。因此**本次无法直连该站点取得真实 HTML 抓包**，HTML 结构结论来自多方独立解析器交叉验证（下文逐条标注置信度）。

### 2.3 北邮专用单元格格式（`QzWithNodeParser`）

北邮的课表单元格用 `title` 属性标注语义，这与普通强智部署不同（这正是 WakeupSchedule 为北邮单独采用
`TYPE_QZ_WITH_NODE` 而不是 `TYPE_QZ` 的原因）。

来源：https://github.com/xianfei/WakeupSchedule_BUPT
`app/src/main/java/com/suda/yzune/wakeupschedule/schedule_import/parser/qz/QzWithNodeParser.kt`

```kotlin
val courseName = Jsoup.parse(infoStr.substringBefore("<font").substringBefore("<span>").trim()).text()
val teacher = courseHtml.getElementsByAttributeValue("title", "老师").text().trim()
val room = courseHtml.getElementsByAttributeValue("title", "教室").text().trim()
         + courseHtml.getElementsByAttributeValue("title", "分组").text().trim()
val tempStr = courseHtml.getElementsByAttributeValue("title", "周次(节次)").text()
// 周次取 '(' 之前；节次取 ')' 之后 "[..-..节]"
val weekStr = ... .substringBefore(')')
val nodeList = ... .substringAfter(')').removeSurrounding("[", "]").split('-')
```

**因此单元格 HTML 的结构（由解析器反推，非逐字抓包）大致为：**

```html
<td>
  <div class="kbcontent">
    高等数学A<br>
    <font title="老师">张三</font><br>
    <font title="周次(节次)">1-16(周)[01-02节]</font><br>
    <font title="教室">教1-201</font><br>
    <font title="分组">01</font>
    ---------------------<br>
    大学英语<br>
    <font title="老师">李四</font><br>
    <font title="周次(节次)">3-5,7-9(周)[03-04节]</font><br>
    <font title="教室">教3-105</font>
  </div>
</td>
```
> ⚠️ 上例是**结构示意**，不是从北邮服务器抓下来的逐字 HTML。逐字抓包需要校园网/WebVPN + 登录态，本次环境不具备。

**旁证（由真实北邮课表页生成的解析说明）** —— https://github.com/Wzzz233/bupt-schedule `SKILL.md`
```
**Course cell format (single line):**
课程名 教师名 N-N(周)[节段] 教室
Example: `高等数学 张教授 1-16(周)[01-02节] 教1-201`
```
它同时给出（对真实页面的观察）：
- 行 0 表头：`["", "星期一", "星期二", "星期三", "星期四", "星期五", "星期六", "星期日"]`
- 第 1–14 行 = 第 1–14 节
- 第 15 行 = 备注（备注里的课不在网格中）
- 第 16 行以后 = 其它信息表（忽略）
- 时间列格式：`N HH:MM-HH:MM`（例：`"1 08:00-08:45"`）
- 同格多门课用 `---------------------` 分隔（≥4 个 `-`；解析器常用 `-{4,}` 或 `-----`）
- 一门课跨多行时同一段文字会**重复出现**，需要按「课程名+星期+节次」去重

`NcepuJw` 对单元格文本分组给出的结构是
`[课程号-序号, 课程名, 周次, 教室, (教师)?]`，且指出**每格内有两个 div**：
可见的 `kbcontent1`（含周次/教室）与隐藏的 `kbcontent`（`display:none`，是分组/教师变体，无周次行）；
解析时**优先取含「周」的那个**，否则会把教师行当成教室。
（`JwClient.kt` 中 `DIV_RE = /<div[^>]*\bclass="kbcontent\d*"[^>]*>([\s\S]*?)<\/div>/`，
`GROUP_SPLIT_RE = /-{4,}/`，且注释警告：**服务端模板对 div 属性输出不稳定**，属性顺序/空白会变，必须容忍。）

> 注意：北邮的 `kbcontent` 与 NCEPU 的差异在于北邮用 `<font title=...>` 标注语义；
> 稳健做法是**同时**尝试「读 `title` 属性」和「按 `<br>` 拆行的纯文本」两条路。

### 2.4 DOM 结构与节次标签

- 行标签 `<th>` 内含「第X大节」或节次号+时间：
  `ROW_LABEL_RE = /第\s*([一二三四五六七八九十])\s*大节/`（NcepuJw，7 大节部署）
- 北邮的实测说明则称有 14 行、每行标签形如 `N HH:MM-HH:MM`（14 小节部署）
  → **行粒度由 `kbjcmsid`（课表节次模式）决定**，不同模式/校区行数不同。
  **建议 App 不要硬编码行数，而应读取行标签里的时间。**

```ts
const AES_KEY = 'qzkj1kjghd=876&*';
function buildPwd(password: string) {
  const key = CryptoJS.enc.Utf8.parse(AES_KEY);
  const plaintext = JSON.stringify(password);
  const encrypted = CryptoJS.AES.encrypt(plaintext, key, {
    mode: CryptoJS.mode.ECB, padding: CryptoJS.pad.Pkcs7
  }).toString();
  return btoa(encrypted);
}
```
即 `pwd = base64( AES-128-ECB( JSON.stringify(密码) , key="qzkj1kjghd=876&*", PKCS7 ) )`。

## 3. 一周课表的判定依据

### 3.1 学期参数
- `xnxq01id` 格式 `YYYY-YYYY-N`，N=1 秋季 / 2 春季（例：`2025-2026-1`）。
  `NcepuJw/README.md` 明确指出：**`xnxq01id` 是唯一学期参数，传新版强智的 `xnm`/`xqm` 会被静默忽略**。
- 页面下拉里可读到当前学年学期与当前周次：`Wzzz233/bupt-schedule:SKILL.md`
  > Look for text like `2024-2025-2 第8周`. The semester and current week are needed to calculate the semester start date.

### 3.2 周次表示法（原始字符串）

| 出现位置 | 形态 |
|---|---|
| PC 课表格 `title="周次(节次)"` | `1-16(周)[01-02节]`、`3-5,7-9(周)[03-04节]`、`9(周)[05节]` |
| PC 课表格（其他强智部署） | `1-16周`、`1-16周(单)`、`3-5,7-9周`、`{第1-16周}` |
| 移动教务 JSON `classWeek` | 区间串，如 `1-16`、`1-4,6-16`、`5` |
| 移动教务 JSON `classWeekDetails` | **逗号分隔的周次集合**，如 `1,2,3,...,16`（最省事） |

来源：
- https://github.com/xianfei/WakeupSchedule_BUPT `QzWithNodeParser.kt`（`1-16(周)[01-02节]`）

## 5. WebVPN 访问方式

### 5.1 结论：北邮用的是**网瑞达（wengine-vpn）**，格式是「AES 加密 host + hex」

- 登录页实测 HTML（HTTP 200）：`https://webvpn.bupt.edu.cn/`
  - 标题 `北京邮电大学WebVPN系统`
  - 资源路径 `/wengine-vpn/js/...`、`/wengine-vpn/js/aes-js.js`
  - `<meta name="keywords" content="WebVPN,WEBVPN,VPN,clientless vpn,**网瑞达**,北京网瑞达科技有限公司,...">`
  - Cookie：`wengine_vpn_ticketwebvpn_bupt_edu_cn`
  - 未登录访问任意代理 URL 均 302 → `https://webvpn.bupt.edu.cn/login`

**因此：不是 `.../http/77726476706e69737468656265737421...` 那种纯 hex 形式的老版？
—— 实际是新版加密，但 magic 前缀仍然是 `77726476706e69737468656265737421`（见下）。**

### 5.2 精确规则

```
原始:  https://<host><path>[?query]
代理:  https://webvpn.bupt.edu.cn/https/<enc(host)><path>[?query]
带端口: https://webvpn.bupt.edu.cn/<protocol>-<port>/<enc(host)><path>[?query]
       （protocol ∈ http | https | ssh | vnc | telnet | rdp）

enc(host) = hex(iv) + hex( AES-CFB128( key, iv, host 右侧补 '0' 至 16 字节的整数倍 ) )[: len(host)*2 ]
key = iv = "wrdvpnisthebest!"        # = 0x77726476706e69737468656265737421
```

- `hex("wrdvpnisthebest!")` = `77726476706e69737468656265737421`
  → 这正是你在问题里给出的 `http/77726476706e69737468656265737421` 前缀的来源。
- **BUPT 未自定义 key/iv**：`data/webvpn.json` 中北邮条目只有 `{"host": "webvpn.bupt.edu.cn"}`，
  没有 `crypto_key`/`crypto_iv`，故用默认值。
  来源：https://github.com/lcandy2/webvpn-converter `data/webvpn.json`（`"北京" → "北京邮电大学"`）
- 算法实现：https://github.com/lcandy2/webvpn-converter `src/app/_libs/url-convert.ts` + `src/app/_libs/config.ts`
  ```ts
  const { KEY, IV } = URL_CONVERT_CONFIG;   // KEY: 'wrdvpnisthebest!', IV: 'wrdvpnisthebest!'
  const AesCfb = aesjs.ModeOfOperation.cfb; // new AesCfb(keyBytes, ivBytes, 16) → CFB128
  const encryptHost = ({text, key, iv}) => {
    const textBytes = utf8.toBytes(textRightAppend(text, 'utf8'));  // 补 '0' 到 16 的倍数
    const encryptBytes = createAesCfb(key, iv).encrypt(textBytes);
    return hex.fromBytes(utf8.toBytes(iv)) + hex.fromBytes(encryptBytes).slice(0, text.length * 2);
  };
  return `${schoolHost}/${protocol}/${encryptedHost}${path}`;
  ```
- **Android/Kotlin 现成实现**（可直接搬）：
  https://github.com/abcde2333/NcepuJw `app/src/main/java/com/ncepu/jw/data/Webvpn.kt`
  ```kotlin
  private const val KEY_STR = "wrdvpnisthebest!"
  fun encHost(host: String): String {
      val key = KEY_STR.toByteArray(Charsets.UTF_8)
      val pad = 16 - (host.length % 16)
      val padded = (host + "0".repeat(pad)).toByteArray(Charsets.UTF_8)
      val ct = aesCfb128(key, key, padded).copyOfRange(0, host.length)
      return key.toHex() + ct.toHex()
  }
  // Cipher.getInstance("AES/CFB128/NoPadding")，失败回退 BouncyCastle
  ```
  该仓库 README 明确写了同一条公式：
  > `enc(host) = hex(iv) + AES-CFB128(key, iv, host补'0'到16的倍数)[:len(host)]`，`key = iv = "wrdvpnisthebest!"`

## 8. 给 Android App 的实现建议（基于以上证据）

1. **首选移动教务 JSON**：`https://jwglweixin.bupt.edu.cn/bjyddx`
   - `POST /login` → `{userNo, pwd: base64(AES-ECB(JSON.stringify(pwd), "qzkj1kjghd=876&*", PKCS7)), encode:"1", captchaData:"", codeVal:""}` → `token`
   - `POST /student/curriculum {week, kbjcmsid}` + header `token` → JSON（字段见 §2.5）
   - `POST /teachingWeek` → 周次↔日期；`POST /Get_sjkbms` → 节次模式
   - ⚠️ 需注意 `endTIme` 这个拼写错误；`weekDay` 的 `"0"` 也代表周日
   - ⚠️ **未验证**：该 API 是否需要验证码（`captchaData`/`codeVal`）、是否有频率限制
2. **次选 PC HTML**：`/jsdx/xskb/xskb_list.do`，`#kbtable` + `div.kbcontent`
   - 稳健解析：先剥 HTML 注释 → 取 `id="kbtable"` 的 table → 每行 `<th>` 取节次/时间标签 →
     每格取 `div[class^=kbcontent]` → 按 `-{4,}` 分段 → 每段按 `<br>` 拆行、
     **优先用 `font[title]` 属性取「老师/周次(节次)/教室」**，取不到再退回按行位置解析
   - 备用数据源：`xskb_print.do` 的 `.xls`（OLE2 签名 `D0 CF 11 E0`），规整且易解析
     （每课 7 行：课程号/名/分组/教师/周次/教室/节次）
3. **校外访问**：用 §5.2 的 AES-CFB128 方案把 `jwgl.bupt.edu.cn` 包成
   `https://webvpn.bupt.edu.cn/https/77726476706e69737468656265737421fae0469069327d406a468ca88d1b203b/...`，
   先 `POST /do-login?local_login=true` 拿 `wengine_vpn_ticket*` Cookie。
   Android 用 `Cipher.getInstance("AES/CFB128/NoPadding")`（BouncyCastle 兜底）。
4. **节次时间**直接内置 §4 的官方 14 节表；**但行标签里的时间更权威**，优先解析；海南校区需切 `kbjcmsid`。
5. **周次↔日期**用 `teachingWeek` 或「第1周周一 + (week-1)*7 + (weekday-1)」；注意第 0 周。
